# WhisperFly — питч-презентация для конкурса стартапов

Презентация проекта [WhisperFly](https://github.com/dandysuper/WhisperFly) на русском языке.
13 слайдов, оформление — тема **VARSITY** из Design Studio (campus letterman: плотная
геометрия, жёсткие тени, кремовый фон, флагманский синий и золотой).

## Что в папке

| Файл | Что это |
|---|---|
| `index.html` | **Основная презентация.** Открывается в любом браузере, работает без сервера |
| `WhisperFly-Pitch-RU.pdf` | Готовый PDF, 13 страниц 16:9 — то, что обычно просят приложить к заявке |
| `WhisperFly-Pitch-RU.pptx` | **Редактируемая** версия для PowerPoint / Keynote / Google Slides |
| `theme.css` | Тема VARSITY: все токены, шрифты, анимации |
| `deck.css` | Вёрстка слайдов. Только `var(--tp-*)`, никаких «сырых» значений |
| `app.js` | Навигация по слайдам |
| `build_pptx.py` | Генератор `.pptx` (палитра считается из тех же oklch-токенов, что и CSS) |
| `assets/favicon.svg` | Эмблема-крест с осциллограммой |

## Как показывать

Откройте `index.html` двойным щелчком — сервер не нужен.

| Клавиша | Действие |
|---|---|
| `→` `Space` `Enter` | Следующий слайд |
| `←` | Предыдущий слайд |
| `Home` / `End` | Первый / последний слайд |
| `F` | Полноэкранный режим |
| Свайп влево/вправо | Перелистывание на тачпаде |

Адрес слайда сохраняется в ссылке (`index.html#7`), так что можно отправлять ссылку
сразу на нужный слайд. Кнопки «Назад / Вперёд / PDF» и точки внизу — тоже навигация.

## Как получить PDF

Кнопка **PDF** в интерфейсе (или `⌘P` → «Сохранить как PDF»). Слайды уже размечены
по одной странице на лист в ландшафтной ориентации, 16:9.

Файл `WhisperFly-Pitch-RU.pdf` в папке собран так:

```bash
CHS=~/Library/Caches/ms-playwright/chromium_headless_shell-*/chrome-headless-shell-mac-arm64/chrome-headless-shell
"$CHS" --headless --no-pdf-header-footer --virtual-time-budget=20000 \
  --print-to-pdf=WhisperFly-Pitch-RU.pdf \
  file://$(pwd)/index.html
```

## Как пересобрать `.pptx`

```bash
pip install python-pptx
python3 build_pptx.py      # → WhisperFly-Pitch-RU.pptx
```

Палитра в скрипте не подобрана на глаз: функции `oklch()` считает те же
`oklch(0.44 0.16 262)` и `oklch(0.78 0.14 417)`, что и CSS-токены `--tp-acc` / `--tp-acc-2`.
Меняете `--tp-h` в теме — меняете и `.pptx`.

> **Шрифты.** `.pptx` ссылается на **Unbounded**, **Rubik** и **JetBrains Mono**
> (все с полной кириллицей, свободные, есть в Google Fonts). Если на машине, где
> открывают файл, их нет — PowerPoint подставит свои, вёрстка поедет. Для защиты
> лучше показывать `index.html` или PDF: там шрифты подтягиваются автоматически.

## Что стоит проверить до конкурса

Слайды 1–6, 9–13 целиком построены на фактах из репозитория
(функции, стек, число локалей, коммитов, сборок, формулировки про macOS 26).
А вот три блока — это **предложение, а не отчётность**, и их нужно подставить свои:

- **Слайд 7 «Рынок»** — TAM $5,2 млрд / SAM $780 млн / SOM $12 млн и темпы роста
  оценены по публичным данным о рынке ASR. Замените на цифры из вашего исследования.
- **Слайд 8 «Бизнес-модель»** — цены (690 ₽ / от 490 ₽), маржа и LTV/CAC это план.
  Сейчас приложение полностью бесплатное и с открытым кодом.
- **Слайд 13 «Что мы ищем»** — формулировка запроса (инвестиции / менторы / партнёры).
  Подставьте то, что реально нужно.

Ещё два места, где стоит пройтись по тексту:

- **Слайд 9 «Конкурентная среда»** — тарифы и возможности конкурентов указаны
  на начало 2026 года. Перед защитой сверьтесь с их сайтами.
- **Слайд 12 «Команда»** — основатель указан по нику `dandysuper`. Если нужны имя,
  фото и фамилия — добавьте.

## Про типографику

Тема VARSITY в оригинале использует **Bungee** и **Figtree**, но у обоих нет
кириллицы — на русском заголовки упали бы в системный шрифт и развалили вёрстку.
Поэтому заголовки набраны **Unbounded**, текст — **Rubik**: тот же громкий
геометрический характер, но с полным кириллическим покрытием. JetBrains Mono
оставлен как в теме.
