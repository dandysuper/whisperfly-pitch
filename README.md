# WhisperFly — презентация для защиты проекта

Питч проекта [WhisperFly](https://github.com/dandysuper/WhisperFly) на русском языке.
**9 слайдов** — ровно по структуре, которую задаёт конкурс (титул, введение, уникальность,
КПД, план реализации, ожидаемые результаты, финансовая часть, команда, заключение).
Оформление — тема **VARSITY** из Design Studio (campus letterman: плотная геометрия,
жёсткие тени, кремовый фон, флагманский синий и золотой).

Формат сдачи покрыт полностью: **сайт**, **PDF** и **PPTX**.

| Что просит конкурс | Где это в презентации |
|---|---|
| Ссылка на сайт | <https://dandysuper.github.io/whisperfly-pitch/> |
| PDF | `WhisperFly-Pitch-RU.pdf` — 9 страниц, 16:9 |
| PPTX | `WhisperFly-Pitch-RU.pptx` — редактируемая версия |

## Как показывать

Откройте `index.html` двойным щелчком — сервер не нужен.

| Клавиша | Действие |
|---|---|
| `→` `Space` `Enter` | Следующий слайд |
| `←` | Предыдущий слайд |
| `Home` / `End` | Первый / последний слайд |
| `F` | Полноэкранный режим |
| Свайп влево/вправо | Перелистывание на тачпаде |

Адрес слайда сохраняется в ссылке (`index.html#7`), так что можно отправлять ссылку
сразу на нужный слайд. Кнопки «Назад / Вперёд / PDF» и точки внизу — тоже навигация.

## Как получить PDF

Кнопка **PDF** в интерфейсе (или `⌘P` → «Сохранить как PDF»). Слайды размечены
по одной странице на лист: 16:9, 1280×720. Файл `WhisperFly-Pitch-RU.pdf` собран так:

```bash
CHS=~/Library/Caches/ms-playwright/chromium_headless_shell-*/chrome-headless-shell-mac-arm64/chrome-headless-shell
"$CHS" --headless --no-pdf-header-footer --virtual-time-budget=25000 \
  --print-to-pdf=WhisperFly-Pitch-RU.pdf \
  http://127.0.0.1:8787/index.html
```

## Как пересобрать `.pptx`

```bash
pip install python-pptx
python3 build_pptx.py      # → WhisperFly-Pitch-RU.pptx, 9 слайдов
```

Палитра в скрипте не подобрана на глаз: функция `oklch()` считает те же
`oklch(0.44 0.16 262)` и `oklch(0.78 0.14 417)`, что и CSS-токены `--tp-acc` / `--tp-acc-2`.
Меняете `--tp-h` в теме — меняете и `.pptx`.

> **Шрифты.** `.pptx` ссылается на **Unbounded**, **Rubik** и **JetBrains Mono**
> (все с полной кириллицей, свободные, есть в Google Fonts). Если на машине, где
> открывают файл, их нет — PowerPoint подставит свои, вёрстка поедет. Для защиты
> лучше показывать `index.html` или PDF: там шрифты подтягиваются автоматически.

## Что стоит проверить до защиты

Слайд 1 (название, логотип, команда), слайды 2–3 и 8 построены на фактах из репозитория:
версия 2.0, системный звук, транскрипция файлов, история, 11 языков интерфейса, открытый
исходный код, macOS 14+. Их менять не нужно.

А вот **четыре блока — это предложение, а не отчётность**, и цифры там ваши:

- **Слайд 4 «КПД»** — расчёт эффекта: 10 000 пользователей × 40 минут × 220 рабочих дней
  ≈ 1,5 млн человеко-часов. Подставьте своё допущение по числу пользователей и экономии.
- **Слайд 5 «План реализации»** — сроки этапов (Q1–Q4 2026). Сверьте с тем, что реально
  успеваете.
- **Слайд 6 «Ожидаемые результаты»** — 10 000 установок, 500 платящих, 3 внедрения,
  конверсия 5 %, удержание 35 %. Это цели, а не обещания: их спросят.
- **Слайд 7 «Финансовая часть»** — смета и запрашиваемая сумма **4 500 000 ₸** на 12 месяцев
  (2 400 000 — оплата труда, 600 000 — маркетинг, 500 000 — оборудование, 360 000 — API,
  300 000 — юр./бух., 54 000 — сертификаты Apple, 286 000 — резерв). Подставьте свои суммы.

Ещё два места, где стоит пройтись по тексту:

- **Слайд 3 «Уникальность»** — тарифы и возможности конкурентов указаны на начало 2026 года.
  Перед защитой сверьтесь с их сайтами.
- **Слайд 1 и 8 «Команда»** — спикер указан как **Даниил Бурыкин** (взят из локального
  `git config`). Если нужны другое имя, фамилия или фото — правьте `index.html`
  (блок `.title-meta` и `.crew`) и `build_pptx.py` (функции `slide_title`, `slide_team`).

## Про типографику

Тема VARSITY в оригинале использует **Bungee** и **Figtree**, но у обоих нет
кириллицы — на русском заголовки упали бы в системный шрифт и развалили вёрстку.
Поэтому заголовки набраны **Unbounded**, текст — **Rubik**: тот же громкий
геометрический характер, но с полным кириллическим покрытием. JetBrains Mono
оставлен как в теме.

## Публикация

Сайт собирается из ветки `main` (корень репозитория) — GitHub Pages отдаёт его
по адресу <https://dandysuper.github.io/whisperfly-pitch/>. Достаточно запушить:

```bash
git push origin main
```

Через минуту после пуша обновятся и сайт, и PDF по прямой ссылке.
