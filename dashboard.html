Как это работает

Три источника звука — один путь до текста

Облачный ASR, а не локальная модель

Приложение весит мегабайты, а не гигабайты: модель живёт на сервере, Mac не греется и не ждёт загрузки.

Вставка через Accessibility API

Текст появляется там, где стоит курсор, — без буфера обмена и без ручного ⌘V.

Системный звук через ScreenCaptureKit

Созвоны и видео транскрибируются прямо с аудиодорожки Mac, а не через динамики в микрофон.
